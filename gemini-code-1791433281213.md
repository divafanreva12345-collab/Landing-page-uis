# 🛡️ LAPOR NDAN - Sistem Pelaporan Anonim

LAPOR NDAN adalah platform web pelaporan warga berbasis anonim yang dirancang khusus untuk wilayah Tangerang Selatan. Aplikasi ini memungkinkan warga untuk melaporkan potensi bentrok, perundungan (bullying), atau indikasi penyalahgunaan miras dan narkoba secara aman, rahasia, dan terpercaya.

## ✨ Fitur Utama
- **100% Anonim**: Identitas pelapor tidak direkam oleh sistem.
- **Akses Kamera Langsung**: Mendukung pengambilan bukti foto secara *real-time* menggunakan kamera smartphone (Kamera Belakang).
- **Live Preview & Hapus**: Pengguna dapat melihat *preview* foto sebelum dikirim dan menghapusnya jika kurang sesuai.
- **Desain Responsif**: Antarmuka bersih, rapi, dan responsif untuk berbagai ukuran layar smartphone maupun PC (dibangun menggunakan Tailwind CSS).

## 🚀 Teknologi yang Digunakan
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (untuk navigasi DOM dan File API)
- FontAwesome (untuk ikonografi)

## 📱 Cara Penggunaan
1. Buka aplikasi melalui *browser* HP atau PC.
2. Pilih kategori pelanggaran yang ingin dilaporkan.
3. Masukkan lokasi kejadian secara spesifik (misal: "Dekat warkop simpang tiga").
4. Ketik kronologi singkat kejadian.
5. Ketuk area kamera untuk mengambil foto bukti secara langsung atau unggah dari galeri.
6. Klik **Kirim Laporan Anonim**.

## 📌 Catatan Pengembangan
Versi saat ini adalah *Front-end / User Interface*. Untuk tahap selanjutnya, form ini dapat dihubungkan ke layanan *Back-end* (seperti Google Sheets API, Firebase, atau PHP/MySQL) untuk menyimpan data laporan secara permanen.
